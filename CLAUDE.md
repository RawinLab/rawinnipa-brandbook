## What this repo is

Rawinnipa's complete brand system. Every file here represents an approved brand asset. Source scripts in `scripts/` regenerate every output — so this repo is **parametric**, not just a dump of static files.

When the user asks for anything brand-related — a new social post, a tweaked KV, a pitch deck cover, a business card — **check this repo first**. The answer usually already exists, or can be generated by running a script.

## Non-negotiable brand rules

Violating any of these is a **bug**, not a style choice. Refuse or flag if asked to override.

### Colors (hex only, no `#` in PPTX)

| Token | Hex | When to use |
|---|---|---|
| Rawin Green *(primary)* | `#3EDC81` | Accent, CTA, brand moment (1 per composition) |
| Deep Teal | `#23B591` | Gradient start, secondary |
| Lime Accent | `#9DC351` | Gradient end, tertiary |
| Deep Black | `#0A0A0A` | Default background |
| Charcoal | `#1A1A1A` | Card/surface on dark |
| Off White | `#F7F7F7` | Light-mode background |

Full neutrals + Pantone in `01-strategy/Rawinnipa_Brand_Guidelines_v1.0.md` §4.

### Typography

- **English** — Inter (Bold / Semibold / Regular)
- **Thai** — Noto Sans Thai (Bold / Regular)
- **Fallback** — Calibri (Office documents only)
- **Never** — Arial, Helvetica, Times, any decorative font

> Noto Sans Thai on most Linux distros is a **Thai-only subset** — it lacks Latin/digits. When rendering mixed Thai+English strings in PIL, use `draw_mixed()` in `scripts/build_kv.py` which splits runs by Unicode block.

### Tagline

- **English:** "Build what moves."
- **Thai:** "สร้างระบบที่ขับเคลื่อนธุรกิจ."
- The period after "moves" / "ธุรกิจ" is intentional. Don't drop it.
- The word "**moves.**" / "**ธุรกิจ.**" is always in **Rawin Green** when it appears alongside the rest of the tagline in white.

### Logo

- Only use the 4 variants in `02-logo/`. Never recolor, never add effects, never rotate.
- Minimum clear space = ¼ of the logo's height on every side.
- Minimum size: 24 px digital / 15 mm print.
- Six explicit don'ts listed in Brand Guidelines §3.4.

### Layout defaults

- Dark canvas is default. Light canvas only when explicitly requested.
- One green accent per composition. Don't flood the frame with green.
- Inter/Noto Sans Thai Bold for headlines; Regular for body.

## Regeneration commands

All scripts write into `/home/claude/brand_ci/` (or local equivalent). After running, copy outputs back into the relevant numbered folder and commit.

```bash
# Prerequisites (one-off)
npm install -g pptxgenjs react react-dom react-icons sharp
pip install --break-system-packages Pillow numpy
apt install -y fonts-inter fonts-noto-core

# Regenerate each output
node scripts/build_brand_ci.js      # → Brand Guidelines PPTX
node scripts/build_brand_cv.js      # → Company CV PPTX
python3 scripts/build_kv.py         # → All 9 key visuals
```

To change a **tagline, color, or layout**: edit the relevant script and rerun. Never hand-edit a rendered output — it will drift out of sync with the source.

## When you're uncertain

1. **Read `01-strategy/Rawinnipa_Brand_Guidelines_v1.0.md` first** — it's the source of truth.
2. **If the user's request would violate a brand rule** (e.g., "make the logo red"), flag it and quote the relevant section. Offer the closest on-brand alternative.
3. **If you need new copy** (new tagline, new subheadline), match the [brand voice rules](01-strategy/Rawinnipa_Brand_Guidelines_v1.0.md#71-writing-rules) — direct, plain-spoken, concrete. No hype.
4. **Don't invent new logo variants.** If the 4 existing ones don't fit, tell the user and suggest which existing variant is closest.

## Output conventions

When you create new files in this repo:

- **Naming** — lowercase with underscores (e.g., `kv_twitter_1500x500.png`, not `KV Twitter.png`)
- **Location** — match the numbered folder system (strategy → `01-`, logo → `02-`, etc.)
- **Dimensions in filename** — for KVs, always include `_WIDTHxHEIGHT`
- **Versioning** — for updated documents, suffix with `_vMAJOR.MINOR` (e.g., `_v1.1`)
- **Commits** — follow the existing format: `feat(scope): one-line summary` + body

## Non-goals

- **Do not** write to `01-strategy/*.pptx` or `*.pdf` directly — always rerun `scripts/build_brand_ci.js` instead.
- **Do not** generate new fonts, color tokens, or visual motifs without the user asking explicitly and updating the Brand Guidelines in the same change.
- **Do not** push to Git automatically — commits are fine, pushing is the user's call.
- **Do not** use stock imagery without a licensing note; the brand uses only geometric/gradient elements by default.
