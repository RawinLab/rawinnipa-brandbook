# Rawinnipa A4 envelope artwork

Two print-ready, front-side A4 files (297 × 210 mm, landscape) for printing directly on kraft-brown stock:

- `envelope_a4_english.pdf`
- `envelope_a4_thai.pdf`

Matching 300 dpi PNG files are included for each language.

The PDF pages have no brown background. Artwork uses Deep Black (`#0A0A0A`) only, with a 16 mm safe margin at left and 15 mm at top.

Source HTML files are included for future copy changes.
