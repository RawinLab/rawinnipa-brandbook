# Rawinnipa C4 envelope artwork

Two print-ready, front-side C4 envelope files (324 × 229 mm, landscape) for printing directly on kraft-brown stock:

- `envelope_c4_english.pdf`
- `envelope_c4_thai.pdf`

The PDF pages have no brown background. Artwork uses Deep Black (`#0A0A0A`) only, with a 16 mm safe margin at left and 15 mm at top. The sender line uses the publicly stated location, Bangkok, Thailand, because no street address is defined in the brand repository.

Source HTML files are included for future copy changes.
